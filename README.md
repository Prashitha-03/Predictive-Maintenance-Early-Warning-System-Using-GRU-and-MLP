# Predictive Maintenance Warning System

This project develops a predictive model for detecting early warning signs in industrial sensor data such as vibration, pressure, and flow rate changes. The system uses GRU and MLP models to analyze time-series data and identify abnormal patterns for predictive maintenance.

## Technologies Used
- Python
- TensorFlow
- NumPy
- Pandas
- Scikit-learn

## Dataset
Simulated industrial sensor dataset.
